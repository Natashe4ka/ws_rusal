# Подготовка исходников к публикации

## Состав репозитория

В Git входят код, конфигурации, URDF, тесты, небольшая контактная фикстура,
документация и сводные результаты. Модели KUKA подключаются отдельным submodule
с закреплённой ревизией. Локальные `results/`, окружения, сборки и внутренние
отчёты исключены через `.gitignore`.

## Проверка перед первым push

```bash
git status --short
git diff --cached --stat
git submodule status
.venv/bin/python -m pytest -q
.venv/bin/python scripts/package_source.py
```

Скрипт упаковки использует состав индекса Git, исключает саму базу `.git`
и содержимое submodule, проверяет недопустимые машинные пути и крупные файлы.
ZIP-архив содержит `SOURCE_MANIFEST.json` с SHA-256 файлов. Зависимость KUKA
для архива загружается командой `python3 scripts/bootstrap_robot.py`.

Первый коммит, удалённый репозиторий, доступность и push оформляются отдельно
после выбора целевого репозитория. Подготовка архива не публикует данные
и не изменяет права доступа GitHub.

Для повторяемого результата не обновляйте submodule без проверки модели.
Сверяйте ревизию с `robot-model.lock.json` и сохраняйте upstream-уведомления.
