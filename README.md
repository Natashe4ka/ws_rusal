# rusal-sim

Физическая симуляция роботизированного извлечения алюминиевых чушек из навалки
и укладки на паллету. Модель включает KUKA KR 50 R2500, свободные твёрдые тела,
вакуумно-механический захват, контактное взаимодействие и ограниченные усилия
приводов. Динамику рассчитывает MuJoCo; восприятие, планирование и интерфейсы
управления реализованы программными имитаторами.

## Состояние проекта

Исследовательский прототип. Он предназначен для проверки отдельных физических
сценариев, а не для управления промышленной ячейкой.

| Сценарий | Размещено | Строгий критерий качества | Условия |
| --- | ---: | ---: | --- |
| Компактная навалка, гибридный захват | 5/5 | 5 | 7,5 кг на чушку, зазоры 40 мм |
| Контролируемые стопки | 12/12 | 12 | Номинальные чушки 7,5 кг |
| Партия с разбросом размеров и массы | 10/10 | 2 | 12–14 кг, повторные подборы и продолжения |
| Перекрёстная укладка партии 24 шт. | 11/24 | 2 | Остановка по самоконтакту корпуса захвата с губкой |

При итоговом аудите последнего сценария 10 из 11 ранее размещённых деталей
оставались в границах паллеты. Полный разбор партии из 24 деталей не подтверждён.
Исходные условия, трактовка критериев и ограничения приведены в
[результатах испытаний](docs/experimental_results.md).

## Требования

- Linux; проверенное окружение — Ubuntu 24.04 и Python 3.12.
- Python 3.12 или новее, Git, OpenGL/EGL для визуализации.
- Модели KUKA из закреплённой внешней зависимости.
- ROS 2 Jazzy и MoveIt 2 нужны только для ROS-моста и отдельных интеграционных
  опытов. Автономный расчёт `sim` работает без ROS.

## Установка

Команды выполняются из корня клонированного репозитория:

```bash
git submodule update --init --recursive
python3 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
```

Если исходники получены ZIP-архивом, загрузите зависимость отдельно:

```bash
python3 scripts/bootstrap_robot.py
```

Версия KUKA закреплена на commit
`5ddbc41ce8726fd680bcc19562d78bcabfbdf96d`. Полный upstream содержит другие
семейства роботов и занимает около 1 ГБ; в собственный репозиторий его файлы
не копируются. `requirements-local.lock` фиксирует прямые зависимости исходного
проверенного окружения, включая системные пакеты Ubuntu; это не универсальный
lock-файл для установки на другой платформе.

Проект используется из исходного checkout через editable-установку: конфигурации,
описание робота и внешние модели находятся рядом с Python-пакетом. Отдельная
установка wheel без дерева проекта не поддерживается.

## Запуск

Пять деталей в компактной навалке, гибридный захват:

```bash
./run_sim.sh --config configs/hybrid_foam_jaws.yaml --count 5 --seed 42 --speed 4
```

Партия 24 детали, размеры 380–420 × 190–210 × 30–50 мм, масса 12–14 кг,
паллет 1200 × 800 × 180 мм, до трёх слоёв с поворотом на 90°:

```bash
./run_cross24.sh --speed 4
```

Расчёт без графического окна:

```bash
./run_cross24.sh --headless --out results/logs/cross24_check
```

Первый запуск формирует и проверяет навалку. Повторный запуск использует
сохранённое состояние, если оно соответствует конфигурации и прошло проверку
равновесия. `--speed` задаёт темп отображения; скорость численного расчёта зависит
от сложности контактов и оборудования.

Управление окном: `Space` — пауза, `=` / `+` — быстрее, `-` — медленнее,
`Esc` — выход. Полная справка:

```bash
.venv/bin/rusal-sim sim --help
```

## Проверки

```bash
.venv/bin/python -m pytest -q
```

Тесты используют временные каталоги и сохранённую контактную фикстуру в
`src/rusal_mujoco/tests/fixtures`. Локальные журналы предыдущих опытов не нужны.
Последняя локальная проверка: 47 тестов, все пройдены; отдельно проверены
распаковка исходников и запуск из другого каталога. Подробности —
[сводка проверки](docs/validation/checks.json). Workflow GitHub Actions настроен
на тот же набор в чистом checkout.

## Структура

| Каталог | Назначение |
| --- | --- |
| `src/rusal_mujoco/rusal_sim/` | Динамика, геометрия, захват, планирование, CLI и ROS-мост |
| `src/rusal_mujoco/tests/` | Физические и регрессионные проверки |
| `src/rusal_description/urdf/` | Развёрнутая модель KUKA и xacro-обёртка |
| `src/rusal_motion_planning/launch/` | Запуск интеграционного опыта MoveIt |
| `src/third_party/kuka_robot_descriptions/` | Внешний Git submodule |
| `configs/` | Параметры физики, захватов и сценариев |
| `scripts/` | Вспомогательные команды, аудит и упаковка исходников |
| `docs/` | Описание модели, результаты, ограничения и инструкции |
| `results/` | Локальные выходные данные; не входят в Git |
